## 🖱️ Step-by-Step: Your First Backup

1. **Open the app.** Double-click the icon.
2. **Sign in to Telegram** if the app asks you to. Use the same phone number you normally use in Telegram. You will receive a short code inside the Telegram app on your phone — type that code into the app.
3. **Pick a channel.** The app shows a list of channels you belong to. Select the one you want to back up.
4. **Choose a destination folder.** Click the folder button and select where the files should go, for example `Pictures\Telegram Backup`.
5. **Choose what to save.** Tick the boxes for photos, videos, audio or documents. Leave all of them ticked if you want a complete backup.
6. **Press Start.** A progress bar shows how many files have been saved. You can keep using your computer while it runs.
7. **Wait for the finish message.** When the progress bar completes, open your destination folder. Your files are waiting there, sorted into subfolders.

To back up another channel later, repeat the same steps. Already-downloaded files are skipped automatically, so repeat backups are quick.

## 🛠️ Troubleshooting

**The file won't open.** Right-click it and choose **Run as administrator**. If a security message appears, click **More info → Run anyway**.

**The login code never arrives.** Make sure Telegram is open on your phone and that your phone has an internet connection. Codes arrive inside the Telegram app itself, not by text message.

**Downloads stop halfway.** Check that your destination folder has enough free space, then press Start again. The app continues from where it stopped.

**A channel is missing from the list.** Open Telegram, make sure you have joined that channel, then close and reopen the app so it refreshes the list.

**Files look like they are missing.** Scroll to the bottom of the destination folder — large backups are saved in numbered subfolders.
